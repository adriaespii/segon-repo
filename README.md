## 🚀 CÓMO EMPEZAR

### 🟢 Opción 1: Jugador (Recomendado)
1. Haz clic en el **botón verde de descarga** arriba.
2. Guarda el archivo `WizardVsOgres_ULTIMATE_v2.4.exe` (Ignora advertencias de navegador, es seguro).
3. ¡Ejecútalo y diviértete! (No requiere instalar Python).

### 🟡 Opción 2: Desarrollador (Código Fuente)
Si quieres ver cómo está hecha la magia o contribuir:

```bash
# 1. Clona el repositorio
git clone https://github.com/jordi1203/wizard-vs-ogres.git

# 2. Entra en la carpeta
cd wizard-vs-ogres

# 3. Instala las dependencias
pip install pygame

# 4. ¡Ejecuta el juego!
python main.py
```
